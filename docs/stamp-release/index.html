STEP 00 · コマ12

一覧と詳細から再開する

Visual Studio Codeで、自分のスタンプ帳のフォルダを開きます。既にF01StampBoardとして作っている場合は名前を変えず、その1本を育てて構いません。まだ無い場合はTerminalで次を実行し、生成したF02StampReleaseをFile > Open Folder…で開きます。同名フォルダへ上書きしません。

mkdir -p ~/Documents/HybridApp
cd ~/Documents/HybridApp
flutter create --empty --platforms=ios,android --org jp.ac.jec --project-name f02_stamp_release F02StampRelease

SDKはFlutter 3.47.5 / Dart 3.13.4です。不足分は共通の準備資料を授業中に確認します。既存のiOSランタイムを使い、flutter upgradeはしません。

lib/main.dartを下の開始コードへそろえます。自分が変えた文字・色は先に控えます。pubspec.yamlのdependencies側のFlutter SDKは残し、dev_dependencies側にflutter_testのひな形がある場合はそのブロックだけ除きます。test/のひな形も生成されていた場合だけ除き、flutter_lintsは残します。

Terminal > New Terminalでflutter pub getを実行し、Flutter: Launch Emulatorで既存のiOSシミュレータを起動します。flutter devicesでIDを読み、flutter run -d 端末IDで実行します。端末IDは表示された値へ置き換えます。

コードを保存したら、flutter runが動いているターミナルで小文字のrを押すとホットリロードし、現在のStateを保って画面を更新します。初期値やinitStateからやり直す場合は、大文字のR（Shift + R）でホットリスタートします。qは実行の終了です。以後、再起動による確認ではRを使い、保存が未実装の段階では入力した習慣や回数が消えることも確かめます。

開始コード役割
main・StampApprunAppからMaterialAppを起動し、ThemeDataと最初の画面を指定。
Habit名前・理由・回数を保持。requiredは必須の名前付き引数、finalは再代入しないフィールド。
StampBoardPageのStatehabitsを保持し、setStateで回数の変更を通知。buildが値から一覧・合計を作る。
StampMarkscountを受け取り、forと条件演算子でマークを並べる表示専用Widget。
Navigator.push・MaterialPageRoute選んだHabitをHabitDetailPageへ渡し、戻った後も一覧を保持。

childは1部品、childrenは部品のリストです。Column／Rowで縦横、ListViewでスクロール、Wrapで折り返しを指定します。$と波括弧は文字列補間、() =>はコールバックの1式を返す書き方です。全件の一覧・詳細、0〜5の増減を確認します。再起動で0へ戻るのは、この段階では保存していないためです。

Text('${habit.count} / $stampGoal 回')

Java

habit.count = nextCount;
textView.setText(habit.count + " / " + goal + " 回");

JavaでモデルとViewを更新する目的に対し、FlutterではsetStateで値の変更を通知し、その値からWidgetを返します。遷移はSwiftのNavigation Controllerと同じく画面を積み、引数でデータを渡します。

STEP 01 · コマ12

習慣を入力する画面を作る

一覧へ習慣を追加ボタン、移動先にAddHabitPageを置きます。入力内容とメッセージが変わるため、入力画面はStatefulWidgetです。まだ追加処理を使わず、入力画面の追加するボタンは無効にしておきます。

TextFieldへTextEditingControllerを渡すと、入力値をcontroller.textから読めます。コントローラはbuildのたびに作らずStateのフィールドに置き、画面が破棄されるdisposeで各controller.disposeを呼び、最後にsuper.disposeを呼びます。

名前はmaxLength: 40、理由は200文字。InputDecorationのlabelTextは欄の名前、hintTextは入力例、OutlineInputBorderは枠です。理由はminLines: 3、maxLines: 5で複数行にします。bodyをListViewにして、キーボードで表示領域が狭くても下へ動かせる形にします。

戻るボタンはNavigator.popで入力画面を閉じます。PopScopeのcanPopは戻ることを許す指定で、今はtrueです。保存を入れる段階で、処理中の戻る操作を制御するために使います。入力して戻り、再び開くと新しいStateで欄が空になることを確認します。

全コードには、後のSTEPで使う部分も先に入れてあります。空欄を確かめてmessageへ文を入れるsubmitはSTEP 02で、入力画面から一覧へ習慣を渡すonSaveと、渡された習慣を一覧へ加えるaddHabitはSTEP 03で使います。onSaveはAddHabitPageの必須の名前付き引数なので、一覧のopenAddは今からaddHabitを渡します。追加するボタンのonPressedがnullなので、このSTEPではどれも呼ばれません。TextFieldのenabled: trueは入力を受け付ける指定です。canPopと同じく今はtrueで、保存を入れる段階で、保存中の入力を止めるために使います。

Dart

final nameController = TextEditingController();
TextField(controller: nameController)

Java

EditText nameField = findViewById(R.id.name);
String name = nameField.getText().toString();

AndroidのEditTextやiOSのUITextFieldから文字を読む場面に対応します。FlutterではcontrollerをStateに保持し、画面が終わるときに解放します。入力欄を開き直しても残したい場合は別の場所へ保存が必要ですが、まだ行いません。

STEP 02 · コマ12

空欄を確かめる

追加するボタンのonPressedへsubmitを渡します。括弧を付けたsubmit()の実行結果ではなく、押したときに呼ぶ関数を渡します。

submitでは2つのcontroller.textをtrimして前後の空白を除き、どちらかのisEmptyがtrueならメッセージを表示してreturnします。今回は入力を確認しましたという文までで、一覧への追加は次のSTEPです。

  1. 両方を空にして追加するを押します。
  2. 名前を空白だけにして、理由だけ入力して押します。
  3. 両方を入力し、確認の文と名前が表示されることを確かめます。

エラーのたびに欄を消さず、直して再試行できるようにします。理由に改行を入れ、入力が保持されることも見ます。

Dart

final name = nameController.text.trim();
if (name.isEmpty) return;

Java

String name = nameField.getText().toString().trim();
if (name.isEmpty()) return;

trimと空欄の判定はJavaの入力検証に対応します。DartのisEmptyはプロパティとして読みます。結果はダイアログではなく同じ画面のTextへ出し、setStateで変更を通知します。

習慣を追加して戻る

入力確認後にHabitを作り、widget.onSaveへ渡します。onSaveは親が入力画面へ渡した関数で、この段階はvoid Function(Habit)型です。「Habitを受け取り、結果の値を返さない処理」という意味です。

親のaddHabitではsetStateの中でhabits.addを呼びます。入力画面はNavigator.popで閉じ、下に残っている一覧を表示します。widgetはこのStateに対応するAddHabitPageの設定を読むためのプロパティです。

  1. 1件追加し、一覧が4件になったことを確認します。
  2. 追加したカードの「詳しく見る」を押し、名前と理由が詳細に一致するか確認します。
  3. スタンプを押し、一覧・詳細の回数を確かめます。
  4. ホットリスタートし、追加した習慣が消えて初期3件へ戻ることを確認します。

ソースを書き換えたのではなく実行中のListへ加えただけなので、再起動で消えるのはこのSTEPの正常動作です。

final void Function(Habit) onSave;
widget.onSave(Habit(name: name, reason: reason));

Swift

let onSave: (Habit) -> Void
onSave(Habit(name: name, reason: reason))

Swiftのクロージャを画面へ渡す方法と対応します。DartではFunctionの前後で引数と戻り値の型を示します。親のStateだけが一覧を持つため、入力画面へ別の一覧を重複して作りません。

この単元の新概念は非同期処理と、その完了を待つasync / awaitです。DartのFutureは、後で完了する処理の結果を表します。Future<bool>なら、完了後にtrueかfalseを受け取る形です。

asyncを付けた関数の中ではawaitが使えます。awaitでは、その処理の完了後に続きへ進みます。画面全体を同期的に止めて待つのではなく、待っている間も画面を表示できます。保存の完了前に「保存した」と表示したり、入力を消したりしない順番を作ります。

次は流れを読む抜粋で、このSTEPではまだ追加しません。次のSTEPでパッケージと全コードをそろえます。

Dart

final saved = await saveHabits(nextHabits);
if (saved) {
  // 保存成功後の処理へ進む。
}

Java

// 同期処理の順番を読む例
boolean saved = saveNow(nextHabits);
if (saved) {
    // 戻り値を得た後に進む。
}

Javaの同期的な戻り値と比較し、今回はFutureの完了を待って結果を得る点を新しく扱います。Java／Swiftの非同期APIを履修済みとは仮定しません。既知の順次処理から「完了後の続き」と「待機中の画面」を区別します。

文字列リストへ保存する

まずpubspec.yamlのdependenciesへshared_preferences: 2.5.5を加えます。dependenciesは既にあるので二重に作らず、Flutter SDKと同じ字下げで追加します。ほかの設定は残します。

dependencies:
  flutter:
    sdk: flutter
  shared_preferences: 2.5.5

実行中のアプリをqで終了し、flutter pub getを実行します。新しいネイティブプラグインを加えたのでホットリロードだけで済ませず、全コードを更新してflutter run -d 端末IDで起動し直します。

起動し直さずにrで反映すると、ターミナルにはエラーが出ませんが、スタンプを押しても習慣を追加しても「保存できませんでした。」で始まる文が出るだけで、保存できません。続けてRを押すと、画面全体が赤くなりBad state: The SharedPreferencesAsyncPlatform instance must be set.と出ます。rとRはDartのコードを入れ替えるだけで、アプリのビルドをやり直しません。新しいプラグインは、ビルドし直したアプリにだけ組み込まれます。そのときはqで終了し、flutter run -d 端末IDで起動し直します。

importでパッケージを読み込み、StateにSharedPreferencesAsyncを1つ持ちます。保存キーstorageKeyも1か所です。このAPIだけを使い、旧APIやキャッシュ付きAPIを混ぜません。

名前・理由・回数を文字列リストにして保存します。1件は3要素で、2件なら6要素です。回数はcount.toString()で文字列へ変えます。JSONは使いません。

0・1・2コードを15分読む / 理由の文 / 1
3・4・5外を10分歩く / 理由の文 / 0

saveHabitsはawaitでsetStringListを待ち、成功してからhabitsをnextHabitsへ更新します。changeStampは新しいHabitを作り、表示中のオブジェクトを先に変更しません。追加はList.ofで配列を複製して末尾へ加えます。既存のHabitの内容を書き換えない追加だけなら、リストのコピーで足ります。

isSavingをtrueにしてボタンと入力欄を無効にし、待機中の文とLinearProgressIndicatorを表示します。例外はtry / catchで受け、失敗時は元の一覧を保ちます。finallyは成功・失敗どちらでも待機状態を戻す場所です。

onSaveの型はFuture<bool> Function(Habit)へ変わり、入力画面のsubmitもasyncになります。awaitで親の保存を待ち、成功したときだけpopします。失敗なら入力を消しません。awaitの後はmountedを確認し、既に破棄されたStateへsetStateや画面遷移を行わないようにします。保存中は戻るボタンとPopScopeのcanPopも無効にします。

1件追加して「この端末に保存しました。」を確認します。このSTEPは保存だけで、起動時に読む処理はまだありません。再起動すると初期3件を表示する段階です。再起動した後の初期3件の画面でスタンプを押すか習慣を追加すると、保存内容は表示中の一覧で置き換わり、再起動の前に保存した習慣や回数は残りません。保存した内容をまだ読み込んでいない一覧を、そのまま保存するためです。次のSTEPで読み込めるのは、最後に保存した内容です。

await preferences.setStringList(storageKey, values);

STEP 07 · コマ13

起動時に記録を復元する

起動時のinitStateからloadHabitsを呼びます。initState自体をasyncにはせず、別のasync関数へ処理を分けます。読込中はisLoadingをtrue、canSaveをfalseにし、初期値で保存内容を上書きしないようにします。

await preferences.getStringList(storageKey)は未保存ならnullです。その場合だけcreateInitialHabitsを使います。値があればdecodeHabitsで3要素ずつHabitへ戻します。空リストは正しい0件なので、初期3件へ勝手に置き換えません。

  1. 要素数が3の倍数か、余りを求める%で確認します。
  2. 名前と理由を読み、空白だけでないか確認します。
  3. int.tryParseで回数をintへ戻します。変換できなければnullなので、0〜stampGoalの範囲と一緒に確認します。
  4. 異常ならFormatExceptionを投げます。catchで文を表示し、canSaveをfalseのままにします。

不正な保存内容を「未保存」とは扱いません。元の保存キーへ自動で書き込まず、再読み込みと教員への確認を案内します。次のSTEPで本人が選ぶ初期化を作ります。

  1. 新しい習慣を追加し、何回かスタンプを押します。
  2. アプリを終了して再起動するか、開発中はホットリスタートします。
  3. 「保存した記録を読み込みました。」、追加した習慣、回数、詳細の理由を確認します。

Dart

final saved = await preferences.getStringList(storageKey);
final loaded = saved == null ? createInitialHabits() : decodeHabits(saved);

Swift

let saved = UserDefaults.standard.stringArray(forKey: storageKey)
// nilなら既定値、あれば内容を検証して使う。

未保存のnullはSwiftのnilに対応します。AndroidのonCreateやiOSのviewDidLoadで保存値を画面へ戻す目的と同じですが、今回はinitStateから非同期処理を呼びます。読めたことと、アプリで扱える値かの確認を分けます。

初期化と失敗時の表示

初期化ボタンとresetHabitsを加えます。showDialog<bool>が返すFutureをawaitし、やめるならfalse、初期化するならtrueをNavigator.popで返します。ダイアログの外側などで閉じた場合はnullなので、confirmed != trueなら何もしません。

削除するのはpreferences.remove(storageKey)で指定したキー1個だけです。保存領域全体のclearは使いません。削除に成功してから初期のHabit配列へ戻し、保存を再び有効にします。削除に失敗したら元の一覧とエラーの文を残します。

  1. 自分が残す必要のない検証用の記録で、初期化を開いてやめるを押します。記録が残ることを確認します。
  2. 必要な内容は別に控えてから、もう一度開いて初期化するを押します。
  3. 初期3件・回数0へ戻り、再起動しても初期値になることを確認します。

通常の操作で保存・読込に失敗したら、表示された文を先生と確認します。学生の作品へ障害を起こすコードを入れる作業は行いません。

Dart

final confirmed = await showDialog<bool>(/* 確認画面 */);
if (confirmed != true) return;
await preferences.remove(storageKey);

Swift

UserDefaults.standard.removeObject(forKey: storageKey)

キー単位の削除はUserDefaultsのremoveObjectやSharedPreferences.Editor.removeに対応します。今回は確認画面の返答も非同期に待ち、trueのときだけ進みます。取消しや画面を閉じた場合と、削除の確定を区別します。

    setState(() {
      isLoading = true;
      canSave = false;
      message = '保存した記録を読み込み中です。';
    });
    try {
      final saved = await preferences.getStringList(storageKey);
      final loaded = saved == null
          ? createInitialHabits()
          : decodeHabits(saved);
      if (!mounted) return;
      setState(() {
        habits = loaded;
        canSave = true;
        message = saved == null ? '最初の習慣です。スタンプを押してみましょう。' : '保存した記録を読み込みました。';

      setState(() {
        message = '記録を読み込めませんでした。再読み込みするか、必要な記録を確認してから初期化してください。';
      });
    } finally {
      if (mounted) {
        setState(() {
          isLoading = false;
        });
      }
    }

  List<Habit> decodeHabits(List<String> values) {
    if (values.length % 3 != 0) throw const FormatException('記録の数が合いません。');
    final loaded = <Habit>[];
    for (var i = 0; i < values.length; i += 3) {
      final name = values[i];
      final reason = values[i + 1];
      final count = int.tryParse(values[i + 2]);
      if (name.trim().isEmpty ||
          reason.trim().isEmpty ||
          count == null ||
          count < 0 ||
          count > stampGoal) {
        throw const FormatException('記録の形式が合いません。');
      }
      loaded.add(Habit(name: name, reason: reason, count: count));
    }
    return loaded;
  }

  Future<bool> saveHabits(List<Habit> nextHabits) async {
    if (isLoading || isSaving || !canSave) return false;
    setState(() {
      isSaving = true;
      message = '保存中です。';
    });
    try {
      // 名前・理由・回数の順を、読む側のdecodeHabitsとそろえる。
      final values = <String>[];
      for (final habit in nextHabits) {
        values.add(habit.name);
        values.add(habit.reason);
        values.add(habit.count.toString());
      }
      await preferences.setStringList(storageKey, values);
      if (!mounted) return false;
      setState(() {
        habits = nextHabits;
        message = 'この端末に保存しました。';
      });
      return true;
    } catch (error) {
      if (mounted) {
        setState(() {
          message = '保存できませんでした。内容を変えずに残しています。もう一度試してください。';
        });
      }
      return false;
    } finally {
      if (mounted) {
        setState(() {
          isSaving = false;
        });
      }
    }
  }

          name: item.name,
          reason: item.reason,
          count: item == habit ? nextCount : item.count,

      );
    }
    await saveHabits(nextHabits);

  final String reason;
  int count;
}

class StampBoardPage extends StatefulWidget {
  const StampBoardPage({super.key});

  @override
  State<StampBoardPage> createState() => _StampBoardPageState();
}

class _StampBoardPageState extends State<StampBoardPage> {
  final preferences = SharedPreferencesAsync();
  List<Habit> habits = [];
  bool isLoading = true;
  bool isSaving = false;
  bool canSave = false;
  String message = '';

  @override
  void initState() {
    super.initState();
    loadHabits();
  }

  List<Habit> createInitialHabits() {
    return [
      Habit(name: 'コードを15分読む', reason: '気になったアプリの仕組みを、少しずつ読めるようになりたい。'),
      Habit(name: '外を10分歩く', reason: '画面から離れて気分を切り替え、次の作業を気持ちよく始めたい。'),
      Habit(name: '学びを1行メモ', reason: '今日分かったことを自分の言葉にして、明日の自分へ残したい。'),
    ];
  }

  Future<void> loadHabits() async {
    setState(() {
      isLoading = true;
      canSave = false;
      message = '保存した記録を読み込み中です。';
    });
    try {
      final saved = await preferences.getStringList(storageKey);
      final loaded = saved == null
          ? createInitialHabits()
          : decodeHabits(saved);
      if (!mounted) return;
      setState(() {
        habits = loaded;
        canSave = true;
        message = saved == null ? '最初の習慣です。スタンプを押してみましょう。' : '保存した記録を読み込みました。';
      });
    } catch (error) {
      if (!mounted) return;
      setState(() {
        message = '記録を読み込めませんでした。再読み込みするか、必要な記録を確認してから初期化してください。';
      });
    } finally {
      if (mounted) {
        setState(() {
          isLoading = false;
        });
      }
    }
  }

  List<Habit> decodeHabits(List<String> values) {
    if (values.length % 3 != 0) throw const FormatException('記録の数が合いません。');
    final loaded = <Habit>[];
    for (var i = 0; i < values.length; i += 3) {
      final name = values[i];
      final reason = values[i + 1];
      final count = int.tryParse(values[i + 2]);
      if (name.trim().isEmpty ||
          reason.trim().isEmpty ||
          count == null ||
          count < 0 ||
          count > stampGoal) {
        throw const FormatException('記録の形式が合いません。');
      }
      loaded.add(Habit(name: name, reason: reason, count: count));
    }
    return loaded;
  }

  Future<bool> saveHabits(List<Habit> nextHabits) async {
    if (isLoading || isSaving || !canSave) return false;
    setState(() {
      isSaving = true;
      message = '保存中です。';
    });
    try {
      // 名前・理由・回数の順を、読む側のdecodeHabitsとそろえる。
      final values = <String>[];
      for (final habit in nextHabits) {
        values.add(habit.name);
        values.add(habit.reason);
        values.add(habit.count.toString());
      }
      await preferences.setStringList(storageKey, values);
      if (!mounted) return false;
      setState(() {
        habits = nextHabits;
        message = 'この端末に保存しました。';
      });
      return true;
    } catch (error) {
      if (mounted) {
        setState(() {
          message = '保存できませんでした。内容を変えずに残しています。もう一度試してください。';
        });
      }
      return false;
    } finally {
      if (mounted) {
        setState(() {
          isSaving = false;
        });
      }
    }
  }

  Future<void> changeStamp(Habit habit, int change) async {
    if (isLoading || isSaving || !canSave) return;
    final nextCount = habit.count + change;
    if (nextCount < 0 || nextCount > stampGoal) return;
    // 保存に成功するまで、表示中のHabitを直接変更しない。
    final nextHabits = <Habit>[];
    for (final item in habits) {
      nextHabits.add(
        Habit(
          name: item.name,
          reason: item.reason,
          count: item == habit ? nextCount : item.count,
        ),
      );
    }
    await saveHabits(nextHabits);
  }

  Future<bool> addHabit(Habit habit) async {
    final nextHabits = List<Habit>.of(habits);
    nextHabits.add(habit);
    return await saveHabits(nextHabits);
  }

  void openAdd() {
    Navigator.push(
      context,
      MaterialPageRoute<void>(
        builder: (context) => AddHabitPage(onSave: addHabit),
      ),
    );
  }

  Future<void> resetHabits() async {
    if (isLoading || isSaving) return;
    final confirmed = await showDialog<bool>(
      context: context,
      builder: (context) => AlertDialog(
        title: const Text('初期の習慣に戻しますか？'),
        content: const Text('追加した習慣とスタンプを、この端末から消します。必要な記録は先に控えてください。'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context, false),
            child: const Text('やめる'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(context, true),
            child: const Text('初期化する'),
          ),
        ],
      ),
    );
    if (confirmed != true || !mounted) return;
    setState(() {
      isSaving = true;
      message = '初期化中です。';
    });
    try {
      await preferences.remove(storageKey);
      if (!mounted) return;
      setState(() {
        habits = createInitialHabits();
        canSave = true;
        message = '初期の習慣に戻しました。';
      });
    } catch (error) {
      if (mounted) {
        setState(() {
          message = '初期化できませんでした。記録は画面に残しています。';
        });
      }
    } finally {
      if (mounted) {

    setState(() {
      isLoading = true;
      canSave = false;
      message = '保存した記録を読み込み中です。';
    });
    try {
      final saved = await preferences.getStringList(storageKey);
      final loaded = saved == null
          ? createInitialHabits()
          : decodeHabits(saved);
      if (!mounted) return;
      setState(() {
        habits = loaded;
        canSave = true;
        message = saved == null ? '最初の習慣です。スタンプを押してみましょう。' : '保存した記録を読み込みました。';

  List<Habit> decodeHabits(List<String> values) {
    if (values.length % 3 != 0) throw const FormatException('記録の数が合いません。');
    final loaded = <Habit>[];
    for (var i = 0; i < values.length; i += 3) {
      final name = values[i];
      final reason = values[i + 1];
      final count = int.tryParse(values[i + 2]);
      if (name.trim().isEmpty ||
          reason.trim().isEmpty ||
          count == null ||
          count < 0 ||
          count > stampGoal) {
        throw const FormatException('記録の形式が合いません。');
      }
      loaded.add(Habit(name: name, reason: reason, count: count));
    }
    return loaded;

    if (isLoading || isSaving || !canSave) return false;

      message = '保存中です。';
    });
    try {
      // 名前・理由・回数の順を、読む側のdecodeHabitsとそろえる。
      final values = <String>[];
      for (final habit in nextHabits) {
        values.add(habit.name);
        values.add(habit.reason);
        values.add(habit.count.toString());
      }
      await preferences.setStringList(storageKey, values);
      if (!mounted) return false;
      setState(() {
        habits = nextHabits;
        message = 'この端末に保存しました。';
      });
      return true;

        setState(() {
          message = '保存できませんでした。内容を変えずに残しています。もう一度試してください。';
        });
      }
      return false;

          isSaving = false;

STEP 16 · コマ15

自分の作品として仕上げる

自分の題材に合う名前・理由・見出し・入力例をそろえます。「何を続けたい人が使うアプリか」が初期画面から伝わるようにします。本人の私生活を公開する必要はありません。

見た目を変えたら長い名前と改行のある理由でも確認します。目標回数を小さくする場合は、保存済みの回数が新しい上限を超えると読込の検査に通りません。必要な記録を控えてから旧版で初期化するか、変更後の画面で本人が初期化を選びます。

読込の検査は起動時だけなので、r（ホットリロード）で反映したときは行われず、回数がそのまま残ります。3回のまま目標を2にすると「3 / 2 回 · あと-1回」と出て、スタンプを押すは無効になります。1つ戻すは押せる表示ですが、changeStampは目標を超える次の回数を受け付けません。この例のように目標を1回だけ超えているときは、押すと目標の2回に戻ります。2回以上超えているときは、押しても変わりません。目標を超えた回数が残ったままRを押すと読込の検査に通らないので、上のとおり、必要な記録を控えてから初期化を選びます。

保存キー・3要素の並び・検証条件は、見た目のアレンジとは分けます。今回の提出前に新しい保存形式や機能を増やさず、学んだ範囲で仕上げます。

      canSave = false;

  List<Habit> decodeHabits(List<String> values) {
    if (values.length % 3 != 0) throw const FormatException('記録の数が合いません。');
    final loaded = <Habit>[];
    for (var i = 0; i < values.length; i += 3) {
      final name = values[i];
      final reason = values[i + 1];
      final count = int.tryParse(values[i + 2]);
      if (name.trim().isEmpty ||
          reason.trim().isEmpty ||
          count == null ||
          count < 0 ||
          count > stampGoal) {
        throw const FormatException('記録の形式が合いません。');
      }
      loaded.add(Habit(name: name, reason: reason, count: count));
    }
    return loaded;
  }

  Future<bool> saveHabits(List<Habit> nextHabits) async {
    if (isLoading || isSaving || !canSave) return false;
    setState(() {
      isSaving = true;
      message = '保存中です。';
    });
    try {
      // 名前・理由・回数の順を、読む側のdecodeHabitsとそろえる。
      final values = <String>[];
      for (final habit in nextHabits) {
        values.add(habit.name);
        values.add(habit.reason);
        values.add(habit.count.toString());
      }
      await preferences.setStringList(storageKey, values);
      if (!mounted) return false;
      setState(() {
        habits = nextHabits;
        message = 'この端末に保存しました。';
      });
      return true;
    } catch (error) {
      if (mounted) {
        setState(() {
          message = '保存できませんでした。内容を変えずに残しています。もう一度試してください。';
        });
      }
      return false;
    } finally {

        setState(() {
          isSaving = false;
        });
      }
    }

class _StampBoardPageState extends State<StampBoardPage> {
  final preferences = SharedPreferencesAsync();
  List<Habit> habits = [];
  bool isLoading = true;
  bool isSaving = false;
  bool canSave = false;
  String message = '';

  @override
  void initState() {
    super.initState();
    loadHabits();
  }

  List<Habit> createInitialHabits() {
    return [
      Habit(name: 'コードを15分読む', reason: '気になったアプリの仕組みを、少しずつ読めるようになりたい。'),
      Habit(name: '外を10分歩く', reason: '画面から離れて気分を切り替え、次の作業を気持ちよく始めたい。'),
      Habit(name: '学びを1行メモ', reason: '今日分かったことを自分の言葉にして、明日の自分へ残したい。'),
    ];
  }

  Future<void> loadHabits() async {
    setState(() {
      isLoading = true;
      canSave = false;
      message = '保存した記録を読み込み中です。';
    });
    try {
      final saved = await preferences.getStringList(storageKey);
      final loaded = saved == null
          ? createInitialHabits()
          : decodeHabits(saved);
      if (!mounted) return;
      setState(() {
        habits = loaded;
        canSave = true;
        message = saved == null ? '最初の習慣です。スタンプを押してみましょう。' : '保存した記録を読み込みました。';
      });
    } catch (error) {
      if (!mounted) return;
      setState(() {
        message = '記録を読み込めませんでした。再読み込みするか、必要な記録を確認してから初期化してください。';
      });
    } finally {
      if (mounted) {
        setState(() {
          isLoading = false;
        });
      }
    }
  }

  List<Habit> decodeHabits(List<String> values) {
    if (values.length % 3 != 0) throw const FormatException('記録の数が合いません。');
    final loaded = <Habit>[];
    for (var i = 0; i < values.length; i += 3) {
      final name = values[i];
      final reason = values[i + 1];
      final count = int.tryParse(values[i + 2]);
      if (name.trim().isEmpty ||
          reason.trim().isEmpty ||
          count == null ||
          count < 0 ||
          count > stampGoal) {
        throw const FormatException('記録の形式が合いません。');
      }
      loaded.add(Habit(name: name, reason: reason, count: count));
    }
    return loaded;
  }

  Future<bool> saveHabits(List<Habit> nextHabits) async {
    if (isLoading || isSaving || !canSave) return false;
    setState(() {
      isSaving = true;
      message = '保存中です。';
    });
    try {
      // 名前・理由・回数の順を、読む側のdecodeHabitsとそろえる。
      final values = <String>[];
      for (final habit in nextHabits) {
        values.add(habit.name);
        values.add(habit.reason);
        values.add(habit.count.toString());
      }
      await preferences.setStringList(storageKey, values);
      if (!mounted) return false;
      setState(() {
        habits = nextHabits;
        message = 'この端末に保存しました。';
      });
      return true;
    } catch (error) {
      if (mounted) {
        setState(() {
          message = '保存できませんでした。内容を変えずに残しています。もう一度試してください。';
        });
      }
      return false;
    } finally {
      if (mounted) {
        setState(() {
          isSaving = false;
        });
      }
    }
  }

  Future<void> changeStamp(Habit habit, int change) async {
    if (isLoading || isSaving || !canSave) return;
    final nextCount = habit.count + change;
    if (nextCount < 0 || nextCount > stampGoal) return;
    // 保存に成功するまで、表示中のHabitを直接変更しない。
    final nextHabits = <Habit>[];
    for (final item in habits) {
      nextHabits.add(
        Habit(
          name: item.name,
          reason: item.reason,
          count: item == habit ? nextCount : item.count,
        ),
      );
    }
    await saveHabits(nextHabits);
  }

  Future<bool> addHabit(Habit habit) async {
    final nextHabits = List<Habit>.of(habits);
    nextHabits.add(habit);
    return await saveHabits(nextHabits);
  }

  void openAdd() {
    Navigator.push(
      context,
      MaterialPageRoute<void>(
        builder: (context) => AddHabitPage(onSave: addHabit),
      ),
    );
  }

  Future<void> resetHabits() async {
    if (isLoading || isSaving) return;
    final confirmed = await showDialog<bool>(
      context: context,
      builder: (context) => AlertDialog(
        title: const Text('初期の習慣に戻しますか？'),
        content: const Text('追加した習慣とスタンプを、この端末から消します。必要な記録は先に控えてください。'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context, false),
            child: const Text('やめる'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(context, true),
            child: const Text('初期化する'),
          ),
        ],
      ),
    );
    if (confirmed != true || !mounted) return;
    setState(() {
      isSaving = true;
      message = '初期化中です。';
    });
    try {
      await preferences.remove(storageKey);
      if (!mounted) return;
      setState(() {
        habits = createInitialHabits();
        canSave = true;
        message = '初期の習慣に戻しました。';
      });
    } catch (error) {
      if (mounted) {
        setState(() {
          message = '初期化できませんでした。記録は画面に残しています。';
        });
      }
    } finally {
      if (mounted) {
        setState(() {
          isSaving = false;
        });
      }
    }
  }

    Navigator.push(
      context,
      MaterialPageRoute<void>(
        builder: (context) => HabitDetailPage(habit: habit),
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    var total = 0;
    for (final habit in habits) {
      total += habit.count;
    }
    return Scaffold(
      appBar: AppBar(title: const Text('スタンプ帳')),
      body: SafeArea(
        child: ListView(
          padding: const EdgeInsets.all(20),
          children: [
            const Text(
              '小さな「できた」を、\nひとつずつ。',
              style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
            ),
            const SizedBox(height: 8),
            Text('できたときに1つ押そう。まずは各$stampGoal回。'),
            const SizedBox(height: 16),
            Container(
              padding: const EdgeInsets.all(20),
              decoration: BoxDecoration(
                color: const Color(0xFFDDEFE7),
                borderRadius: BorderRadius.circular(20),
              ),
              child: Row(
                children: [
                  const Icon(Icons.auto_awesome, size: 32),
                  const SizedBox(width: 16),
                  Expanded(
                    child: Text(
                      '集めたスタンプ  $total 個',
                      style: const TextStyle(
                        fontSize: 20,
                        fontWeight: FontWeight.bold,
                      ),
                    ),
                  ),
                ],
              ),
            ),
            const SizedBox(height: 20),
            if (isLoading || isSaving) const LinearProgressIndicator(),

            const SizedBox(height: 12),
            FilledButton.icon(

class _AddHabitPageState extends State<AddHabitPage> {
  final nameController = TextEditingController();
  final reasonController = TextEditingController();
  bool isSaving = false;
  String message = '';

  @override
  void dispose() {
    nameController.dispose();
    reasonController.dispose();
    super.dispose();
  }

  Future<void> submit() async {
    if (isSaving) return;
    final name = nameController.text.trim();
    final reason = reasonController.text.trim();

        message = '習慣の名前と、続けたい理由を入力してください。';

      message = '保存中です。';
    });

    if (!mounted) return;
    if (saved) {
      Navigator.pop(context);
    } else {
      setState(() {
        isSaving = false;
        message = '保存できませんでした。入力は残っています。もう一度試してください。';
      });
    }
  }

状態確認するところ
パッケージが見つからないpubspec.yamlのdependenciesへshared_preferencesを入れ、flutter pub getを実行。追加後はアプリを停止して再実行。
パッケージを加えた後、「保存できませんでした。」と出る。Rで画面全体が赤くなる起動し直さずにr・Rで反映した。qで終了し、flutter run -d 端末IDで起動し直す。
保存しても起動後に消えるSTEP 06は保存だけ、07から読み込み。06で再起動した後に押すか追加すると、前の保存は表示中の一覧で置き換わる。保存キーとアプリの実行先が同じか。
読込エラーになる元データを勝手に上書きせず、再読み込み。必要な記録を控えてから本人の判断で初期化。
残り回数が負になる（あと-1回など）回数が目標を超えたままstampGoalを減らし、rで反映した。1つ戻すが効くのは、目標を1回だけ超えているとき。Rでは読込エラーになるので、必要な記録を控えて初期化。
初期値を変えても出ない保存済みデータが優先。必要な記録を控えて初期化し、ソースの初期データを確認。
Androidビルドが止まる回線、SDK・ライセンス、Gradleの版・URL、取得中かエラーかを教員と切り分ける。授業中に不足分を準備。
APKが大きいdebugではなくflutter build apkの通常releaseを使ったか。app-release.apkの容量を確認。
