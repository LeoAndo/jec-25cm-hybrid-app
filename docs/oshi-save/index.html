好きなものノート：追加して、残そう。

日常の中で見つけた好きなものと、好きな理由を画面から追加します。再読み込みしても自分の記録が戻る仕組みを作り、ソースにアレンジを残して公開URLを提出します。

この単元で分かること

新しい考え方はJSONです。画面で使う配列を保存用の文字列にし、読み込んだ文字列を配列へ戻します。保存先はJavaのSharedPreferences・SwiftのUserDefaultsと比較します。

完成見本の名前は M02OshiSave です。学生は自分の好きなものノートを同じ1プロジェクトで育てます。まだプロジェクトがない場合の作り方も、一覧・詳細の開始コードも、この本文にあります。

STEP 00 · コマ5

自分の好きなものノートを開く

Google Chromeで通常版Monacaへログインし、自分の好きなものノートを開きます。続けて使っているプロジェクトは、名前が M01OshiList のままで構いません。今日のためにコピーを増やしたり、削除したりしません。

  1. まだ自分の好きなものノートがない人だけ、ダッシュボードで新規作成し、最小限のテンプレート を選び、M02OshiSave と名付けます。登録や空き枠が不明なら、共通資料のSTEP 2〜3で確認して戻ります。
  2. www/index.html・www/css/style.css を開きます。www/js/app.js がなければ、ファイル一覧の作成操作で www の下に js フォルダ、その中に app.js ファイルを作ります。
  3. 自分のアレンジがある場合は、変えた文字と色を控えます。下の開始コード3ファイルをそろえ、保存してプレビューを再読み込みします。components や res は変更しません。
  4. 3件の名前を押して詳細を開き、左上の戻るボタンで一覧へ戻ります。戻るボタンは、iOS向けの見た目では「＜ 戻る」、Android向けの見た目では左向きの矢印「←」だけです。タイトルと詳細の組み合わせを確かめます。

開始コードの役割を、次の順で追いましょう。新しいファイル名を detail.html として作る操作は不要です。これは index.html の中の template のidです。

場所処理と理由
HTMLのhead標準loader、Onsen UI 2.12.9のCSS・JavaScript、自作CSS・app.jsを読み込む。自作JSはOnsen UIより後。
ons-navigator / templatenavigatorがlist.htmlを実体化する。templateは配置前のひな形で、詳細へ進んだときにdetail.htmlの要素が作られる。
initのリスナーページの要素が使える時点に、そのページのidを見てイベント登録や文字の設定を行う。
oshiItems / renderOshiList配列の件数だけ固定の行構造を作る。名前や種類はtextContentへ入れ、文字をHTMLとして解釈しない。
openOshiDetailpushPageのdataへ選んだデータを渡し、詳細のpage.dataで受け取る。現在のページと移動中の旗を調べ、連打でページを重ねない。
callback / 戻る移動完了のcallbackで旗を戻す。ons-back-buttonはページを1つ戻す。

CSSはクラスで余白・色・カードの枠を対応させています。Onsen UIは同じHTMLへOSに合わせた部品のスタイルを適用します。今回も素のJavaScriptから使い、別のフレームワークは追加しません。

既知の技術と比べる

Web基礎と同じ3ファイル構成ですが、操作する場所はMonaca クラウド IDEです。initはAndroidのビュー生成後の設定やiOSのviewDidLoadに相当するタイミングで、JavaScriptのaddEventListenerで受け取ります。pushPageのdataは、ネイティブアプリで次の画面へ値を渡す操作に対応します。まだ保存用の文字列には変換していません。

function createOshiRowHtml(index) {
  return '<ons-list-item id="item_oshi_' + index +
    '" class="oshi-card" tappable modifier="chevron">' +
    '<div class="center">' +
    '<span class="list-item__title oshi-name" id="txt_name_' +
    index + '"></span>' +
    '<span class="list-item__subtitle oshi-genre" id="txt_genre_' +
    index + '"></span>' +
    '</div>' +
    '</ons-list-item>';
}

function renderOshiList() {
  const listOshi = document.getElementById("list_oshi");
  let html = "";

  for (let i = 0; i < oshiItems.length; i++) {
    html += createOshiRowHtml(i);
  }

  // HTMLを作り直すとイベントも消えるため、全行を置いてから登録する。
  listOshi.innerHTML = html;

  for (let i = 0; i < oshiItems.length; i++) {
    // データに含まれる「<」などを、HTMLではなく文字として表示する。
    document.getElementById("txt_name_" + i).textContent = oshiItems[i].name;
    document.getElementById("txt_genre_" + i).textContent = oshiItems[i].genre;

    const itemOshi = document.getElementById("item_oshi_" + i);
    itemOshi.addEventListener("click", function() {
      openOshiDetail(oshiItems[i]);
    });
  }
}

function openOshiDetail(oshi) {
  const navApp = document.getElementById("nav_app");

  // 続けて押しても、詳細画面を重ねて開かない。
  if (isOpeningDetail || navApp.topPage.id !== "page_list") {
    return;
  }

  isOpeningDetail = true;
  document.getElementById("txt_selected").textContent = "選択中：" + oshi.name;

  navApp.pushPage("detail.html", {
    data: {
      oshi: oshi
    },
    callback: function() {
      isOpeningDetail = false;
    }
  });
}

STEP 01 · コマ5

入力画面を作る

3ファイルをこのSTEPのコードへ更新します。HTMLに add.html のtemplateを加え、名前・種類の input と、好きな理由の textarea を置きます。label のforと入力欄のidが対応します。

CSSの .app-input は幅を100%にし、box-sizing: border-box でpaddingと枠をその幅の内側へ収めます。font: inherit で文字を周囲とそろえ、focusのoutlineで選択中の欄を見分けます。reset用のクラスは後の確認表示で使います。

一覧の btn_open_add へopenAddPageを登録し、pushPage("add.html", ...) で入力画面へ進みます。詳細と同じ移動中の旗を共有するため、片方を開いている最中にもう片方は開きません。

初期データは createInitialItems が新しい配列を返す形にまとめました。後で初期化したときにも同じ内容を作り直せるようにするためです。呼び出しのたびに新しい配列になる点を、returnの位置と一緒に読みます。

  1. 保存・再読み込み後に 好きなものを追加 を押します。
  2. 3つの欄へ文字を入力して、左上の戻るボタンで一覧へ戻ります。もう一度開くと新しい入力画面が作られ、欄は空に戻ります。
  3. このSTEPでは 追加する をdisabledにしてあります。まだクリック処理を付けていないため、押せない状態が正解です。

既知の技術と比べる

Web基礎のinput・textarea・labelをそのまま使います。AndroidのEditText、iOSのUITextField・UITextViewと同じ役割です。画面を開く処理は詳細への移動と同じ形で、渡すデータが要らないためdataを省きます。createInitialItemsは、Java／Swiftでデータの配列を関数から返す書き方と対応します。

  1. 新しい好きなものを1件入力して追加します。一覧が4件になったことを確認します。
  2. 追加した行を押し、名前・種類・好きな理由が入力どおりか確かめます。好きな理由に改行を入れた場合も確認します。
  3. 戻ってからプレビューを再読み込みします。配列はソースの初期データから作り直されるため、3件に戻ります。今日はこれで正解です。

pushはJavaのArrayList.addやSwiftのArray.appendと同じ追加です。popPageはiOSで前の画面へ戻す操作に対応します。ここで変えたのは実行中の配列だけなので、ファイルに文字を保存したときやSharedPreferences／UserDefaultsへ書いたときとは残り方が異なります。

文字列にして保存する

このSTEPの3ファイルへ更新します。JSの先頭に STORAGE_KEY を置き、保存内容を探すための名前を1か所で管理します。この名前を途中で変更すると、以前のキーで保存した内容は見えなくなります。

addOshiでは、oshiItems.slice() で配列の浅いコピーnextItemsを作り、そこへ新しい1件を追加します。この処理では既存のオブジェクトの項目は変更せず、配列へ追加するだけなので、配列のコピーで足ります。

localStorage.setItem(STORAGE_KEY, JSON.stringify(nextItems)) が、同じブラウザの同じ保存領域へ文字列を保存する行です。localStorageは同期APIなので、次の行へ進む前にこの呼び出しが終わります。今回はPromiseやasync / awaitを使いません。

保存設定や空き容量などの理由で書き込めないと例外が発生します。try 内の保存が成功したときだけ、oshiItemsをnextItemsへ替えて一覧を描き直します。catch 側では入力内容を残し、ボタンを戻してエラーを表示し、returnします。

順番そうする理由
別の配列に追加保存前に画面の元データを変えない。
ボタンを無効化して保存同じ入力を連続して処理しない。
成功したら配列更新・一覧再描画・戻る保存失敗を「追加できた」と見せない。
失敗したら画面に理由を出す入力を消さず、次の確認や再試行につなげる。

1件追加して一覧へ戻り、件をこのブラウザに保存しました。 の文を確かめます。このSTEPでは保存までなので、再読み込み時の表示はまだ初期データです。保存されていないと決めつけず、次のSTEPで読み込む側を作ります。

STEP 07 · コマ6

保存した配列を復元する

JSにloadOshiItemsとisValidItemsを加え、page_listのinitで 読み込み→一覧生成 の順に呼びます。保存した値を読む前に行を作ると、初期データのまま表示されるためです。

getItem(STORAGE_KEY) は、未保存なら null を返します。この場合は何も復元せず、ソースの初期データを使います。文字列があればJSON.parseで値へ戻します。

JSONとして読めることと、画面で使えることは別です。たとえば数値のJSONもparseできますが、今回欲しいのは文字列の項目を持つ配列です。isValidItemsは次の順に確かめます。

  1. Array.isArray で配列か確認します。
  2. 各itemがnullでなく、オブジェクトであるかを typeof と条件式で確認します。
  3. name・genre・commentがすべてstringで、trim後に空でないか確認します。先に型を確認するため、文字列でないものへtrimを呼びません。
  4. 全部通ればtrueを返します。空の配列は有効な0件として扱います。

読み込みやparseが失敗したとき、または構造が違うときはcanSaveをfalseにします。保存済みの文字列を自動で消したり、初期データで上書きしたりしません。一覧には初期データと失敗メッセージを表示し、追加は止めます。次のSTEPで、本人が選んだときだけ初期化できる操作を作ります。

  1. 名前に引用符や山かっこ、好きな理由に改行を入れて1件追加します。
  2. 同じプレビューを再読み込みし、保存した件数と追加した行が戻ることを確かめます。
  3. 詳細を開き、文字・改行が入力どおりに戻ったことを確認します。

保存領域はブラウザやプレビューの場所に結び付きます。別の端末・別のブラウザ・別のプロジェクトのコピーへ、内容が自動で移る仕組みではありません。

  }

function loadOshiItems() {
  const txtStorage = document.getElementById("txt_storage");
  txtStorage.textContent = "ソースに書いた初期の内容を表示しています。";
  try {
    const text = localStorage.getItem(STORAGE_KEY);
    if (text === null) {
      return;
    }
    const savedItems = JSON.parse(text);
    // JSONとして読めても、画面に必要な配列・文字列とは限らない。
    if (!isValidItems(savedItems)) {
      canSave = false;
    } else {
      oshiItems = savedItems;
      txtStorage.textContent = oshiItems.length + "件の保存内容を読み込みました。";
    }
  } catch (error) {
    canSave = false;
  }
  if (!canSave) {
    txtStorage.textContent = "保存内容を読み込めません。保存データは変更していません。初期の内容に戻すか、ブラウザの保存設定を先生と確認してください。";
  }
}

function isValidItems(items) {
  if (!Array.isArray(items)) {
    return false;
  }
  for (let i = 0; i < items.length; i++) {
    const item = items[i];
    if (item === null || typeof item !== "object" ||
        typeof item.name !== "string" || typeof item.genre !== "string" ||
        typeof item.comment !== "string") {
      return false;
    }
    if (item.name.trim() === "" || item.genre.trim() === "" || item.comment.trim() === "") {
      return false;
    }
  }
  return true;
}

STEP 08 · コマ6

初期化の確認と失敗への対応

HTMLに初期化ボタンと確認欄、JSにそのイベントとresetOshiItemsを加えます。初期の内容に戻す を押すと、is-hiddenをremoveして確認欄を見せます。やめる ではクラスをaddし、欄を閉じるだけです。

実際の削除は 削除して初期の内容に戻す を押した場合だけです。localStorage.removeItem(STORAGE_KEY) で、このアプリのキー1つだけを削除します。保存領域全体を空にするclearは使いません。

削除に成功したらcreateInitialItemsで新しい初期配列を作り、canSaveをtrueへ戻し、一覧と文を更新します。削除に失敗したら画面の配列も変更せず、削除できなかったと表示します。初期化が終わると、以前入力した内容は戻せません。

  1. 検証用に追加したデータを使い、初期化の確認欄を開いて やめる を押します。件数が変わらないことを確認します。
  2. 残す必要のある内容は控えてから、もう一度確認欄を開き、削除するボタンを押します。
  3. 一覧がソースの初期データに戻り、再読み込みしてもその初期データになることを確かめます。

通常の操作で保存・読込に失敗した場合は、表示された文を先生と確認します。教材の確認のために、ブラウザのセキュリティ設定を変更する必要はありません。

既知の技術と比べる

Web基礎のclassList.add / removeで表示クラスを切り替えます。キー1つの削除は、AndroidのSharedPreferences.Editor.removeやSwiftのUserDefaults.removeObjectに対応します。データを消す前に選び直せる画面を用意する点は、ネイティブアプリの確認操作と同じです。

保存を確かめてアレンジする

入力→追加→詳細→戻る→再読み込みの順で動かし、保存した内容が復元されることを確認します。次に、ソースの初期データを自分の言葉へ変えます。

保存データがあると、ソースの初期データより優先して表示されます。 createInitialItemsを書き換えても画面が変わらない場合は、変更したコードのミスとは限りません。必要な入力を控えたうえで、アプリ内の初期化を使ってソースの内容を確認します。

createInitialItemsのname・genre・comment初期化後の一覧と詳細が自分の好きなものになる。

保存キーは変えず、まず文字や色を変えましょう。保存して再読み込みし、どの変更がソースに残り、どの内容がブラウザだけに残るかを説明します。

既知の技術と比べる

ネイティブアプリでも、コードに書いた既定値より保存済みの設定を優先することがあります。同じ区別を、createInitialItemsとgetItemのどちらが最終的なoshiItemsになるかで追います。アレンジは既習のデータと装飾の変更だけで行います。

function addOshi() {
  const btnSave = document.getElementById("btn_save_oshi");
  const txtMessage = document.getElementById("txt_add_message");
  if (btnSave.disabled || !canSave) {
    return;
  }

  const name = document.getElementById("txt_input_name").value.trim();
  const genre = document.getElementById("txt_input_genre").value.trim();
  const comment = document.getElementById("txt_input_comment").value.trim();
  if (name === "" || genre === "" || comment === "") {
    txtMessage.textContent = "名前・種類・好きな理由をすべて入力してください。";
    return;
  }

  // 保存に成功するまでは、表示中の配列を変えない。
  const nextItems = oshiItems.slice();
  nextItems.push({ name: name, genre: genre, comment: comment });
  btnSave.disabled = true;
  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(nextItems));
  } catch (error) {
    btnSave.disabled = false;
    txtMessage.textContent = "保存できませんでした。入力内容は残しています。ブラウザの保存設定や空き容量を確認してください。";
    return;
  }

  oshiItems = nextItems;
  renderOshiList();
  document.getElementById("txt_storage").textContent = oshiItems.length + "件をこのブラウザに保存しました。";
  document.getElementById("txt_selected").textContent = "追加したもの：" + name;
  document.getElementById("nav_app").popPage();
}

function loadOshiItems() {
  const txtStorage = document.getElementById("txt_storage");
  txtStorage.textContent = "ソースに書いた初期の内容を表示しています。";
  try {
    const text = localStorage.getItem(STORAGE_KEY);
    if (text === null) {
      return;
    }
    const savedItems = JSON.parse(text);
    // JSONとして読めても、画面に必要な配列・文字列とは限らない。
    if (!isValidItems(savedItems)) {
      canSave = false;
    } else {
      oshiItems = savedItems;
      txtStorage.textContent = oshiItems.length + "件の保存内容を読み込みました。";
    }
  } catch (error) {
    canSave = false;
  }
  if (!canSave) {
    txtStorage.textContent = "保存内容を読み込めません。保存データは変更していません。初期の内容に戻すか、ブラウザの保存設定を先生と確認してください。";
  }
}

function isValidItems(items) {
  if (!Array.isArray(items)) {
    return false;
  }
  for (let i = 0; i < items.length; i++) {
    const item = items[i];
    if (item === null || typeof item !== "object" ||
        typeof item.name !== "string" || typeof item.genre !== "string" ||
        typeof item.comment !== "string") {
      return false;
    }
    if (item.name.trim() === "" || item.genre.trim() === "" || item.comment.trim() === "") {
      return false;
    }
  }
  return true;
}

function resetOshiItems() {
  const txtStorage = document.getElementById("txt_storage");
  try {
    // clearではなく、このアプリの保存キーだけを削除する。
    localStorage.removeItem(STORAGE_KEY);
  } catch (error) {
    txtStorage.textContent = "保存内容を削除できませんでした。表示と保存データは変更していません。";
    return;
  }
  oshiItems = createInitialItems();
  canSave = true;
  document.getElementById("btn_open_add").disabled = false;
  document.getElementById("panel_reset").classList.add("is-hidden");
  renderOshiList();
  document.getElementById("txt_selected").textContent = "まだ選択していません";
  txtStorage.textContent = "保存内容を削除し、ソースに書いた初期の内容へ戻しました。";
}

function addOshi() {
  const btnSave = document.getElementById("btn_save_oshi");
  const txtMessage = document.getElementById("txt_add_message");
  if (btnSave.disabled || !canSave) {
    return;
  }

  const name = document.getElementById("txt_input_name").value.trim();
  const genre = document.getElementById("txt_input_genre").value.trim();
  const comment = document.getElementById("txt_input_comment").value.trim();

    return;
  }

  // 保存に成功するまでは、表示中の配列を変えない。
  const nextItems = oshiItems.slice();
  nextItems.push({ name: name, genre: genre, comment: comment });
  btnSave.disabled = true;
  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(nextItems));
  } catch (error) {
    btnSave.disabled = false;
    txtMessage.textContent = "保存できませんでした。入力内容は残しています。ブラウザの保存設定や空き容量を確認してください。";
    return;
  }

  oshiItems = nextItems;
  renderOshiList();
  document.getElementById("txt_storage").textContent = oshiItems.length + "件をこのブラウザに保存しました。";
  document.getElementById("txt_selected").textContent = "追加したもの：" + name;

function loadOshiItems() {
  const txtStorage = document.getElementById("txt_storage");
  txtStorage.textContent = "ソースに書いた初期の内容を表示しています。";
  try {
    const text = localStorage.getItem(STORAGE_KEY);
    if (text === null) {
      return;
    }
    const savedItems = JSON.parse(text);
    // JSONとして読めても、画面に必要な配列・文字列とは限らない。
    if (!isValidItems(savedItems)) {
      canSave = false;
    } else {
      oshiItems = savedItems;
      txtStorage.textContent = oshiItems.length + "件の保存内容を読み込みました。";
    }
  } catch (error) {
    canSave = false;
  }
  if (!canSave) {
    txtStorage.textContent = "保存内容を読み込めません。保存データは変更していません。初期の内容に戻すか、ブラウザの保存設定を先生と確認してください。";
  }
}

function isValidItems(items) {
  if (!Array.isArray(items)) {
    return false;
  }
  for (let i = 0; i < items.length; i++) {
    const item = items[i];
    if (item === null || typeof item !== "object" ||
        typeof item.name !== "string" || typeof item.genre !== "string" ||
        typeof item.comment !== "string") {
      return false;
    }
    if (item.name.trim() === "" || item.genre.trim() === "" || item.comment.trim() === "") {
      return false;
    }
  }
  return true;
}

function resetOshiItems() {
  const txtStorage = document.getElementById("txt_storage");
  try {
    // clearではなく、このアプリの保存キーだけを削除する。
    localStorage.removeItem(STORAGE_KEY);
  } catch (error) {
    txtStorage.textContent = "保存内容を削除できませんでした。表示と保存データは変更していません。";
    return;
  }
  oshiItems = createInitialItems();
  canSave = true;
  document.getElementById("btn_open_add").disabled = false;
  document.getElementById("panel_reset").classList.add("is-hidden");
  renderOshiList();
  document.getElementById("txt_selected").textContent = "まだ選択していません";
  txtStorage.textContent = "保存内容を削除し、ソースに書いた初期の内容へ戻しました。";
}

      return;
    }
    const savedItems = JSON.parse(text);
    // JSONとして読めても、画面に必要な配列・文字列とは限らない。
    if (!isValidItems(savedItems)) {
      canSave = false;
    } else {
      oshiItems = savedItems;
      txtStorage.textContent = oshiItems.length + "件の保存内容を読み込みました。";
    }
  } catch (error) {
    canSave = false;
  }
  if (!canSave) {
    txtStorage.textContent = "保存内容を読み込めません。保存データは変更していません。初期の内容に戻すか、ブラウザの保存設定を先生と確認してください。";
  }
}

function isValidItems(items) {
  if (!Array.isArray(items)) {
    return false;
  }
  for (let i = 0; i < items.length; i++) {
    const item = items[i];
    if (item === null || typeof item !== "object" ||
        typeof item.name !== "string" || typeof item.genre !== "string" ||
        typeof item.comment !== "string") {
      return false;
    }
    if (item.name.trim() === "" || item.genre.trim() === "" || item.comment.trim() === "") {
      return false;
    }
  }
  return true;
}

function resetOshiItems() {
  const txtStorage = document.getElementById("txt_storage");
  try {
    // clearではなく、このアプリの保存キーだけを削除する。
    localStorage.removeItem(STORAGE_KEY);
  } catch (error) {
    txtStorage.textContent = "保存内容を削除できませんでした。表示と保存データは変更していません。";
    return;
  }
  oshiItems = createInitialItems();
  canSave = true;
  document.getElementById("btn_open_add").disabled = false;
  document.getElementById("panel_reset").classList.add("is-hidden");
  renderOshiList();
  document.getElementById("txt_selected").textContent = "まだ選択していません";
  txtStorage.textContent = "保存内容を削除し、ソースに書いた初期の内容へ戻しました。";
}
