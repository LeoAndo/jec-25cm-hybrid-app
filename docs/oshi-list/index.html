好きなものノート：一覧から詳細へ

日常の中で見つけた好きなものをカードに並べ、好きな理由を開いて読めるアプリを作ります。静的なカードから始め、Onsen UIの一覧、配列、詳細画面へ進みます。

Monaca クラウド IDE / Google ChromeOnsen UI 2.12.9HTML / CSS / JavaScript

この単元で分かること

新しい考え方は auto-styling です。1つのHTMLから、OSに合った部品の見た目が選ばれる仕組みを確かめます。配列・イベント・画面の切り替えは、Web基礎・Android・iOSと比べて書き方を読みます。

使うプロジェクトは M01OshiList です。各STEPの「全コード」は開いてコピーでき、各コマの最初には開始時のコードもあります。前から順に作る場合は、説明されたファイルを更新します。途中から合流する場合は、開始時のファイルをすべてそろえてから進みます。

コマこの回の到達点
1通常版Monacaで静的なカードを表示する。
2Onsen UIの一覧とauto-stylingを確認する。
3配列から一覧を作り、押した名前を表示する。
4詳細へ値を渡し、戻る操作まで完成させる。

完成プロジェクトを開く

先生が見本を使うと案内したら、M01OshiListの完成プロジェクトを開くへ進みます。通常版Monacaへログインした状態で、取り込むプロジェクトを確認します。自分の制作を始めるにはSTEP 00へ進みます。

完成見本の取り込みにも1枠を使います。Freeプランの3枠を確認し、URLを繰り返し開いて複数のコピーを作らないようにします。自分の作品は削除しません。配布ZIPの samples/M01OshiList はコードを読むための見本です。

STEP 00 · 1コマ目

授業の準備と、自分のプロジェクト

この単元では M01OshiList という1つのプロジェクトを4コマかけて育てます。Google ChromeでMonaca クラウド IDEを使います。今日は静的なカードまで作ります。この教科書では、好きな音楽、食べ物、場所など、身近なものを集め、好きな理由を読み返せるようにします。自分の好きなものと好きな理由を、自分の言葉でカードにしましょう。M01では、コードに書いた好きなものを集めて読むところまで作ります。画面から入力する機能や、入力した内容を保存する機能はまだ付けません。

  1. 共通資料のSTEP 1〜3で、教材の受け取り、通常版Monacaの登録・ログイン、空き枠の確認を行い、このページへ戻ります。初めての登録とダウンロードも授業内で行います。
  2. Monacaのプロジェクト一覧から新規作成に進み、最小限のテンプレート を選びます。プロジェクト名を M01OshiList として作成し、開きます。既に自分の同名プロジェクトがあれば、その続きを開きます。
  3. ファイル一覧で www/index.html と www/css/style.css を探します。components、res、設定ファイルはそのまま使います。
  4. 下の全コードを開き、2ファイルの内容をそれぞれ置き換えて保存します。プレビューを再読み込みし、好きなものノートを作ります。を確認します。

以後、本文のパスはプロジェクト内の位置です。「全コード」は指定ファイルの中身をすべて置き換えるためのものです。先に比較と説明を読み、貼り付けた後は確認欄の操作まで行いましょう。

STEP 01 · 1コマ目

head の読み込みと設定は残します。最小限のテンプレートが持つ components/loader.js などは、この単元で中身を書き換えるファイルではありません。

押した行の名前を表示する

www/js/app.js を全文に置き換えます。2回目の for の末尾へ、各行の click イベントが増えました。押された行に対応する oshiItems[i] を、selectOshi へ渡します。

for (let i = 0; ...) の let により、登録した関数はその回の番号を使えます。3つの行に同じ0番のデータを渡さず、各回の i で選ぶ点を確認します。

イベントを付けるのは innerHTML = html の後です。行を置き直すと前の行に登録したイベントも失われるため、全行の配置を終えてから登録します。

let isOpeningDetail = false;

// templateの中身は、ページが作られてから取得する。
document.addEventListener("init", function(event) {
  const page = event.target;

  if (page.id === "page_list") {
    renderOshiList();
  }

  if (page.id === "page_detail") {
    const oshi = page.data.oshi;

    document.getElementById("txt_detail_name").textContent = oshi.name;
    document.getElementById("txt_detail_genre").textContent = oshi.genre;
    document.getElementById("txt_detail_comment").textContent = oshi.comment;
  }
});

function createOshiRowHtml(index) {
  return '<ons-list-item id="item_oshi_' + index +
    '" class="oshi-card" tappable modifier="chevron">' +
    '<div class="center">' +
    '<span class="list-item__title oshi-name" id="txt_name_' +
    index + '"></span>' +
    '<span class="list-item__subtitle oshi-genre" id="txt_genre_' +
    index + '"></span>' +
    '</div>' +
    '</ons-list-item>';
}

function renderOshiList() {
  const listOshi = document.getElementById("list_oshi");
  let html = "";

  for (let i = 0; i < oshiItems.length; i++) {
    html += createOshiRowHtml(i);
  }

  // HTMLを作り直すとイベントも消えるため、全行を置いてから登録する。
  listOshi.innerHTML = html;

  for (let i = 0; i < oshiItems.length; i++) {
    // データに含まれる「<」などを、HTMLではなく文字として表示する。
    document.getElementById("txt_name_" + i).textContent = oshiItems[i].name;
    document.getElementById("txt_genre_" + i).textContent = oshiItems[i].genre;

    const itemOshi = document.getElementById("item_oshi_" + i);
    itemOshi.addEventListener("click", function() {
      openOshiDetail(oshiItems[i]);
    });
  }
}

function openOshiDetail(oshi) {
  const navApp = document.getElementById("nav_app");

  // 続けて押しても、詳細画面を重ねて開かない。
  if (isOpeningDetail || navApp.topPage.id !== "page_list") {
    return;
  }

  isOpeningDetail = true;
  document.getElementById("txt_selected").textContent = "選択中：" + oshi.name;

  navApp.pushPage("detail.html", {
    data: {
      oshi: oshi
    },
    callback: function() {
      isOpeningDetail = false;
    }
  });
}
