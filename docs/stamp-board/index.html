小さな「できた」を、スタンプに。

自分が続けたい習慣をカードにし、できたときにスタンプを押すアプリを作ります。画面の部品を一つずつ変更する方法と、値から画面を組み立てる方法の違いを確かめましょう。

STEP 03 · コマ8

ホットリロードはコードの変更を反映し、現在の状態をできるだけ保ちます。RによるホットリスタートはDart側を起動し直します。いまは状態を持たない画面ですが、後の回数の操作で違いが見えます。mainや状態の初期値を変えた場合にはホットリスタートを使います。

styleのfontSizeを28から別の値へ変え、1回ごとの変化を確認します。エラーが出たらターミナルかProblemsの最初のエラーを読み、閉じ括弧・カンマを確認します。実行を終了する場合は実行中のターミナルでqを押します。

Dart

Text('自分の小さな一歩', style: TextStyle(fontSize: 30))

Swift

label.text = "自分の小さな一歩"
label.font = .systemFont(ofSize: 30)

変更する文字とサイズはSwiftのラベル設定と同じ目的です。FlutterではWidgetを記述し直して再表示します。ホットリロードは保存したコードを実行中のアプリへ反映する機能で、ソースを端末内へ永続保存する機能ではありません。

STEP 07 · コマ9

データから一覧を作る

習慣を3件へ増やします。同じカードを3回コピーする代わりに、名前・理由・回数をHabitにまとめ、habitsのリストから作ります。

Habit({required this.name, required this.reason, this.count = 0})は名前付き引数を持つコンストラクタです。requiredは必須、this.nameは受け取った値を同名フィールドへ代入する省略形、count = 0は省略時の初期値です。name・reasonはfinalで一度代入した参照を再代入せず、回数countはintとして後で変更します。

ListViewは縦にスクロールする領域です。childrenの中のfor (final habit in habits) buildHabitCard(habit)で各データからCardを作ります。buildHabitCardは1件をWidgetとして返すメソッドです。この段階の一覧はStatelessWidgetで、操作ボタンはありません。

コード中のvar total = 0は型を推論した変更可能なint、final habitはループの各回で再代入しない変数です。リストをfinalにしても、中身が自動的に変更不可になるわけではありません。

Dart

final habits = [Habit(name: 'コードを15分読む', reason: '仕組みを知りたい')];
for (final habit in habits) buildHabitCard(habit)

Java

for (Habit habit : habits) {
    // 1件ごとのViewを作る
}

HabitのクラスとリストはJavaのデータクラス・ArrayListに対応します。Dartではリストの中にforを置けるため、生成したWidgetをchildrenへ並べられます。Web基礎のDOMを直接生成するコードへ置き換える必要はありません。

このSTEPの全コード（照合・合流用）
lib/main.dart · 全文
import 'package:flutter/material.dart';

const stampGoal = 5;

void main() {
  runApp(const StampApp());
}

class StampApp extends StatelessWidget {
  const StampApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'スタンプ帳',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: const Color(0xFF287A70)),
        scaffoldBackgroundColor: const Color(0xFFF6F7F2),
      ),
      home: StampBoardPage(),
    );
  }
}

class Habit {
  Habit({required this.name, required this.reason, this.count = 0});

  final String name;
  final String reason;
  int count;
}

class StampBoardPage extends StatelessWidget {
  StampBoardPage({super.key});

  final List<Habit> habits = [
    Habit(name: 'コードを15分読む', reason: '気になったアプリの仕組みを、少しずつ読めるようになりたい。'),
    Habit(name: '外を10分歩く', reason: '画面から離れて気分を切り替え、次の作業を気持ちよく始めたい。'),
    Habit(name: '学びを1行メモ', reason: '今日分かったことを自分の言葉にして、明日の自分へ残したい。'),
  ];

  @override
  Widget build(BuildContext context) {
    var total = 0;
    for (final habit in habits) {
      total += habit.count;
    }
    return Scaffold(
      appBar: AppBar(title: const Text('スタンプ帳')),
      body: SafeArea(
        child: ListView(
          padding: const EdgeInsets.all(20),
          children: [
            const Text(
              '小さな「できた」を、\nひとつずつ。',
              style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
            ),
            const SizedBox(height: 8),
            Text('できたときに1つ押そう。まずは各$stampGoal回。'),
            const SizedBox(height: 16),
            Container(
              padding: const EdgeInsets.all(20),
              decoration: BoxDecoration(
                color: const Color(0xFFDDEFE7),
                borderRadius: BorderRadius.circular(20),
              ),
              child: Row(
                children: [
                  const Icon(Icons.auto_awesome, size: 32),
                  const SizedBox(width: 16),
                  Expanded(
                    child: Text(
                      '集めたスタンプ  $total 個',
                      style: const TextStyle(
                        fontSize: 20,
                        fontWeight: FontWeight.bold,
                      ),
                    ),
                  ),
                ],
              ),
            ),
            const SizedBox(height: 20),
            for (final habit in habits) buildHabitCard(habit),
            const SizedBox(height: 8),
            const Text('この段階ではアプリを終了すると回数は0に戻ります。'),
          ],
        ),
      ),
    );
  }

  Widget buildHabitCard(Habit habit) {
    return Card(
      margin: const EdgeInsets.only(bottom: 16),
      color: Colors.white,
      child: Padding(
        padding: const EdgeInsets.all(20),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(
              habit.name,
              style: const TextStyle(fontSize: 20, fontWeight: FontWeight.bold),
            ),
            const SizedBox(height: 12),
            StampMarks(count: habit.count),
            const SizedBox(height: 8),
            Text(
              habit.count == stampGoal
                  ? '$stampGoal回達成！ 小さな積み重ねができました。'
                  : '${habit.count} / $stampGoal 回 · あと${stampGoal - habit.count}回',
            ),
            const SizedBox(height: 12),
            const Text('回数を変える操作は、このあと作ります。'),
          ],
        ),
      ),
    );
  }
}

class StampMarks extends StatelessWidget {
  const StampMarks({super.key, required this.count});

  final int count;

  @override
  Widget build(BuildContext context) {
    return Wrap(
      spacing: 8,
      runSpacing: 8,
      children: [
        for (var i = 0; i < stampGoal; i++)
          Icon(
            i < count ? Icons.check_circle : Icons.radio_button_unchecked,
            color: i < count
                ? const Color(0xFF287A70)
                : const Color(0xFF89958F),
            size: 36,
          ),
      ],
    );
  }
}

STEP 08 · コマ9

配色と表示をそろえる

画面全体の配色をStampAppで指定します。MaterialAppのthemeにThemeData、colorSchemeにColorScheme.fromSeedを渡し、seedColorで基準の色を決めます。Color(0xFF287A70)のFFは不透明度、続く6桁はRGBです。

Scaffoldの背景はscaffoldBackgroundColor、カードの背景はColors.whiteです。TextStyleのfontWeightで文字の太さを指定します。ContainerのBoxDecorationとBorderRadius.circularで合計欄の背景と角を整えます。

合計欄のRowはアイコンと文字を横へ並べ、Expandedが文字へ残りの幅を渡します。StampMarksのWrapは必要なら次の行へ折り返します。ListViewは縦へ動かせるため、下のカードも確認できます。

操作で変わるhabitsをStateへ移します。StampBoardPageはStatefulWidgetとなり、createStateが_StampBoardPageStateを作ります。Widgetは画面の設定、Stateは操作によって変わる値を保持します。名前の先頭のアンダースコアはDartのライブラリ内で使う名前という指定です。

ボタンのonPressedへ() => changeStamp(habit, 1)を渡します。これは引数のない関数で、押したときにchangeStampを呼びます。関数の呼出結果をその場で渡す書き方と区別してください。Dartのアローは1つの式を返す省略形です。

changeStampは次の回数が範囲内か確認し、setState(() { habit.count = nextCount; });で値を変更します。setStateは変更をFlutterへ知らせ、buildで現在の値に合った画面を作り直せるようにします。setStateの中へ画面の部品を追加する操作は書きません。

1回押して、カードの回数・合計・マークが一緒に1になることを確かめます。0に戻す操作も試します。

Dart

onPressed: () => changeStamp(habit, 1)

setState(() {
  habit.count = nextCount;
});

Java

button.setOnClickListener(view -> changeStamp(habit, 1));

ボタンへ処理を渡す目的はJavaのリスナーやSwiftのクロージャと同じです。Dartでは() =>で1式の関数を渡します。値を変えた後に個別のラベルを更新する代わりに、setStateで再構築を知らせます。

STEP 13 · コマ10

上限と戻す操作を確かめる

回数は0〜stampGoalに収めます。ボタン側では、上限ならonPressedをnullにして押せない表示にし、関数側でも範囲外ならreturnします。表示の無効化とデータの範囲確認を両方置きます。

  1. 1件を5回まで押し、達成の文と押せない追加ボタンを確認します。
  2. 1つ戻して4回にし、追加ボタンがまた使えることを確認します。
  3. 0回まで戻し、1つ戻すが無効になることを確認します。
  4. もう一度1回押し、ホットリロードでは1回が残ることを見ます。
  5. ホットリスタートすると、保存していないため初期値0へ戻ることを確かめます。

アプリをバックグラウンドへ移すだけでは終了せず、回数が残ることがあります。再起動の検証と混同しないようにします。

Dart

onPressed: habit.count < stampGoal
    ? () => changeStamp(habit, 1)
    : null

Java

button.setEnabled(habit.count < goal);

Javaでenabledを切り替える目的に対応します。FlutterのボタンはonPressedがnullなら無効です。nullを呼ぶ関数として書くのではなく、押したときの処理が無いことを値で表しています。

回数と見た目をアレンジする

ファイル先頭のstampGoalを5から3や7へ変え、上限・マークの数・残り回数・達成の文がそろうことを確認します。目標を減らす前には回数を0へ戻すか、ホットリスタートします。ホットリロードでは回数が残るため、5回のまま目標を3にすると「5 / 3 回 · あと-2回」と出ます。1つ戻すは押せる表示ですが、changeStampが目標を超える次の回数を受け付けないため、押しても変わりません。そのときはホットリスタートで0へ戻します。

final int goal = 3;

STEP 16 · コマ11

Navigatorで詳細を開く

カードに詳しく見るを加え、openDetail(habit)を呼びます。openDetailはNavigator.pushへcontextとMaterialPageRouteを渡し、ルートのbuilderでHabitDetailPageを作ります。

Navigatorは画面の重なりを管理します。pushで詳細を上に載せるため、一覧のStateは下に残ります。MaterialPageRouteの<void>は、この画面から結果の値を受け取らない指定です。builderのcontextは新しい画面を作る場所の情報です。

詳細のAppBarには戻る操作が自動で付きます。この単元では名前付きルートや追加パッケージを使わず、移動先の型と渡す値が同じ場所で見える書き方にします。

  1. 1件目を1回押してから、詳しく見るを押します。
  2. 詳細の名前と回数が選んだカードに一致することを確かめます。
  3. 戻ると一覧の1回が残ることを確かめます。

Dart

Navigator.push(context, MaterialPageRoute<void>(
  builder: (context) => HabitDetailPage(habit: habit),
));

Swift

let detail = DetailViewController()
detail.habit = habit
navigationController?.pushViewController(detail, animated: true)

Swiftのナビゲーションで次の画面へ値を渡して積む操作に対応します。Flutterはコンストラクタの名前付き引数habitで渡します。一覧を作り直して置き換える操作ではないため、戻ったときのStateを保持できます。

受け取った習慣を表示する

HabitDetailPageは受け取ったHabitを表示するだけなのでStatelessWidgetです。const HabitDetailPage({super.key, required this.habit})でhabitを必須にし、finalフィールドへ保持します。

本文はSafeAreaの中のListViewへ名前・StampMarks・回数・理由を並べます。続けたい理由のTextStyleはheight: 1.7で行間を確保します。長い理由は折り返し、縦の領域が足りなければスクロールできます。

一覧と詳細で同じStampMarksを使うため、目標回数や色の基準がそろいます。詳細へ新しいcountの状態は作りません。受け取ったhabit.countをそのまま表示します。

class HabitDetailPage extends StatelessWidget {

  final Habit habit;
  // buildでhabitを表示する。
}

final class DetailModel {
    let habit: Habit
    init(habit: Habit) { self.habit = habit }
}

一覧と詳細を通して確かめる

最後に一覧と詳細を通して動かします。説明を読めるだけでなく、変更したデータが操作中も一致することを確かめます。

  1. 一覧で初期3件と合計0を確認します。
  2. 1件を5回まで押し、上限を確認して1つ戻します。
  3. 詳しく見るで名前・4回・理由が合うことを確認します。
  4. 戻って別のカードも操作し、合計と各回数の関係を確認します。

flutter analyzeをプロジェクトのターミナルで実行し、指摘があれば最初の行から直します。実行中のflutter runとは別のターミナルを開いて構いません。解析は画面操作の確認を代わりに行うものではありません。

状態確認するところ
flutterが見つからない共通資料のSDK・PATHを確認し、Visual Studio Codeとターミナルを開き直す。
pubspec.yamlが見つからないFile > Open Folder…でF01StampBoardそのものを開く。親のHybridAppではない。

画面が変わらない保存、実行中のプロジェクト、ホットリロードの結果を確認。初期値の変更はホットリスタート。
括弧のエラーが出た最初のエラーから確認。childは1つ、childrenはリスト。各STEPの全文で閉じ括弧を照合。
再起動すると0に戻ったこの単元はメモリだけ。保存していないため正常。
残り回数が負になり、1つ戻すが効かない回数が目標を超えたままstampGoalを減らし、ホットリロードした。ホットリスタートで0に戻す。
