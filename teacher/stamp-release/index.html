F02StampRelease：追加・保存・APK提出

入力した習慣を保存し、再起動で復元する仕組みを作ります。保存の完了と画面更新の順序を確かめ、実際に提出するAPKをインストールして確認します。

Flutter / Visual Studio CodeFlutter 3.47.5 / Dart 3.13.41コマ90分 × 4

この単元の教材方針

新概念はFuture・async / awaitによる非同期処理の1つです。Futureの結果、await後の続き、待機中の画面、成功と失敗を1つの処理の流れとして教えます。Java／Swiftの非同期APIを履修済みとは仮定せず、同期的な順次処理との比較から始めます。

入力はコマ12の同期処理で先に完成させ、コマ13で保存完了を待つ形へ変更します。毎コマの開始コード、新規作成・配置・実行手順は本単元へ再掲し、前の教科書へ送りません。学生は自分の既存のスタンプ帳を続けてよく、配布見本のF02という名前に合わせてコピーを増やす必要はありません。

shared_preferencesは旧SharedPreferences、キャッシュ付きSharedPreferencesWithCache、キャッシュを持たないSharedPreferencesAsyncの3系統があります。本単元はSharedPreferencesAsyncのみを使い、APIを混ぜません。2.5.5を指定し、解決済みのプラットフォーム実装はpubspec.lockへ記録します。

保存形式は名前・理由・回数の3つ組を並べたList<String>です。MonacaやJSONをFlutterの前提にしません。大規模な構造・移行・検索を扱うデータベースではなく、固定した小さな記録の例です。パッケージは重要なデータの永続性を保証する用途には使わず、必要な記録を別に控えるよう説明します。

保存成功前には表示中のHabitを変更しません。読込失敗・不正データは未保存とは区別し、追加・スタンプを無効にして上書きを止めます。空リストは有効な0件です。初期化は確認後に自分のキー1個だけを削除し、clearで全体を消しません。保存中の戻る操作を止め、awaitの後にmountedを確認します。

Material SDKは授業で固定した版で有効なのでpackage:flutter/material.dartを使い、material_uiへ移行しません。3画面の小規模アプリなのでNavigator.pushとMaterialPageRouteにそろえ、名前付きルートやgo_routerを使いません。通信・通知・日付・アカウント・削除編集・保存形式の移行を外し、追加と保存に絞ります。完成アプリのUnit Testは追加しません。

APK提出と採点

提出先・締め切り・指定ファイル名は教員が授業中に案内します。提出先の容量上限は100MB以上またはなしと確認済みなので、flutter build apkの通常APKを使います。実測の完成見本は48,666,844 bytes（約48.7MB）です。学生が素材を変えた場合も容量を確認します。

提出対象はapp-release.apkの確認済みの写しで、debug APKやプロジェクトZIPではありません。生成テンプレートのdebug鍵を使い、署名鍵の作成やストア公開は扱いません。教員は別の検証端末で初期アレンジ、空欄、追加、保存、再起動、詳細、0と上限を確認します。入力済みの記録はAPKに入らないため、createInitialHabitsなどソースに残るアレンジを評価します。

同じapplicationIdの学生作品は上書きインストールで既存データが残る場合があります。教員の採点専用端末で、前の採点用コピーと必要な記録を整理したうえで新規状態を確認します。学生の制作端末や本人の必要なデータを一律に消させません。

検証と未確認項目

Flutter 3.47.5で完成版と全20 STEPの静的解析は指摘なしです。Android 17の専用arm64エミュレータで最終release APKをインストールし、追加・保存・5回上限・取消し・詳細・再起動時の名前／理由／回数の復元・初期化の取消しと確定を確認しました。Androidの空欄検証も確認済みです。STEP 03の途中コードはAndroidで起動し、入力した習慣が一覧に現れ、再起動で初期の3件に戻ることを確認しました。

リポジトリ外の検証コピーで保存失敗時の回数維持と入力保持、不正データで追加が無効になること、空リストの正常な0件表示を確認しました。iOS 26.5／iPhone 17 Proでは起動・スタンプ保存・空欄検証を確認しました。iOSの全操作、全中間STEPの端末実行、学生全員のSDK組み合わせ、教室の初回同時取得時間は未確認です。スクリーンショットは掲載していません。教科書HTMLのブラウザ表示は、ローカルプレビュー用オリジンへのアクセス承認待ちのため未確認です。

教材登録時に4検査（教材整合性、スクリプト250テスト、翻訳抽出、学生用ZIP生成）、スニペット・完成版ミラーのバイト一致、配布ZIPの内容一致を確認済みです。保存失敗を起こすコードは学生の作品へ入れず、検証用コピーも配布しません。
