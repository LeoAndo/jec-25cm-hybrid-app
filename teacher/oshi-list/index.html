この単元の教材方針

新概念は auto-stylingの1つです。同じHTMLでiOS向けとAndroid向けの部品の見た目が変わることをSTEP 08で確かめます。API名や構文がWeb基礎で初出という理由だけでは新概念に数えず、Java / Android・Swift / iOSに既習の対応物があれば、比較STEPで違いと理由を説明します（2026-09-23オーナー方針）。

受講生はHTML・CSS・JavaScriptとJava・Swiftを書いた経験があります。文法の入門を繰り返すのではなく、Webでの記法、画面の生成時点、OS別スタイルを比較します。初回は登録・ダウンロード・作成にも時間を割きます。宿題として環境を用意させる前提にはしません。

カード例とアレンジの問い

完成例は「好きな音楽／音楽」「カレー／食べ物」「公園／場所」の3件です。日常の中で見つけた「好きなもの」と、その好きな理由を記録します。M01は、コードに書いた好きなものをカードに集めて読む範囲です。名前は好きな曲名や食べ物、場所などへ変えられます。個人的な話の開示は必須にせず、架空の例でも構いません。

アレンジでは「自分の好きなものは何か」「どんなところが好きか」を問い、名前と理由を本人の言葉へ変えてもらいます。名前を変えるだけで終えず、好きな理由を短い文で説明できることを確認します。

意図的に外したもの

  • 入力フォーム・編集・削除・保存は扱いません。一覧と詳細、auto-stylingに集中し、授業中の選択が再読み込みで戻ることを明示します。
  • 外部API通信、認証、写真・通知などのCordovaプラグインは使いません。ブラウザだけで操作できる範囲にします。
  • Vue / React / AngularJSなどのフレームワーク、ビルドツール、追加のUIライブラリは使いません。Onsen UIは版を固定して、素のJavaScriptから操作します。
  • JSのアロー関数、クラス構文、テンプレート文字列を使いません。文字列連結はWeb基礎のプラス記号で書きます。
  • OSの内部部品の再実装、画面遷移の独自アニメーション、複雑なナビゲーション設計は扱いません。Onsen UIの既定の動きを確かめます。
  • APK・実機配布はこの単元の課題にしません。Flutter系の教材では承認済みの通常APK提出を維持しますが、M01の前提にしません。

コンソールに出たのは、各読み込みで1件ずつの cordova.js の読み込み失敗だけでした。components/loader.js はUAがモバイルのときだけ http://127.0.0.1/cordova.js（ポート番号なし）を読みに行くため、404ではなく接続拒否になります。プラグインは呼ばないので、画面と操作への影響はありません。STEP 17で続けて押したときのエラーは、次に記します。
