## 書き方の決まり

jec-25cm-kotlin の zh-Hans 用語集と同じ決まりにしてある。

- 操作は短い指示文にする。各STEPの確認欄の文は、画面で確かめられる結果か、できるようになったことを述べる文にする（……已显示／能够说明……）。「我已确认」のような一人称にしない。
- 通常の引用は “…”、中国語の句読点を使う。実際に画面・アプリに出る日本語は「」ごと保持し、中国語の意味を（）で毎回添える。
- 中国語と英字の語・コード（`<code>`・`<strong>` の英字）のあいだには半角スペースを入れる（在 Visual Studio Code 中、打开 <code>lib/main.dart</code>）。中国語と算用数字のあいだには入れない（第1节课、步骤3）。中国語の句読点の前後にはスペースを入れない。
- 並べるときの中黒「・」は使わず、頓号「、」にする。見出しの「A・B」は 与 でつなぐ。「A・Bとの比較」のように 与 が重なるときは、内側を 和 でつなぐ（与 Android Studio 和 Xcode 的比较）。
- 範囲の「〜」は全角の波ダッシュ「～」（U+FF5E）にする（STEP 00～13）。
- 全角のかっこ（）は中国語の全角かっこ（）にする。
- 教科書自身のUI（コピーボタン、進捗表示）は `config/i18n.json` の `ui` と同じ文字にする（已确认 0 / 7 个步骤）。
- IDE のボタン名を動詞に使う原文（Runして確かめる）は、点击 Run 确认 のように 点击 を補う。英語の表示名は英語のまま。
