## Monacaの画面に出る言葉（日本語のまま残し、訳をかっこで添える）

Monacaは日本語表示で使う。画面の言葉は訳さずに残し、うしろにこの表の訳をかっこで添える（例：**プロジェクト → 公開…** (프로젝트 → 공개…)）。かっこの訳は意味を伝えるためのもので、Monacaの韓国語表示の文字と同じとは限らない。日本語を残した言葉のうしろの助詞は、翻訳用skillの韓国語の注意のとおり、かっこの訳ではなく日本語を読んだ音で選ぶ。

| 画面の言葉 | かっこに添える訳 | 場所 |
| --- | --- | --- |
| ファイル | 파일 | クラウドIDEのメニュー |
| 編集 | 편집 | クラウドIDEのメニュー |
| 表示 | 보기 | クラウドIDEのメニュー |
| 実行 | 실행 | クラウドIDEのメニュー |
| ビルド | 빌드 | クラウドIDEのメニュー |
| プロジェクト | 프로젝트 | クラウドIDEのメニュー |
| 設定 | 설정 | クラウドIDEのメニュー |
| ヘルプ | 도움말 | クラウドIDEのメニュー |
| 公開… | 공개… | プロジェクトメニュー |
| インポート | 가져오기 | ダッシュボード |
| 新しいプロジェクトを作る | 새 프로젝트 만들기 | ダッシュボード |
| クラウドIDEで開く | 클라우드 IDE에서 열기 | ダッシュボード |

| プレビュー | 미리보기 | クラウドIDEの画面 |
