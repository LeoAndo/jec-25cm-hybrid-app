## Monacaの画面に出る言葉（日本語のまま残し、訳をかっこで添える）

Monacaは日本語表示で使う。画面の言葉は訳さずに残し、うしろにこの表の訳をかっこで添える（例：**プロジェクト → 公開…**（專案 → 公開…））。日本語と同じ字になる言葉は、かっこ書きを添えない。かっこの訳は意味を伝えるためのもので、Monacaの中国語表示の文字と同じとは限らない。

| 画面の言葉 | かっこに添える訳 | 場所 |
| --- | --- | --- |
| ファイル | 檔案 | クラウドIDEのメニュー |
| 編集 | 編輯 | クラウドIDEのメニュー |
| 表示 | 檢視 | クラウドIDEのメニュー |
| 実行 | 執行 | クラウドIDEのメニュー |
| ビルド | 建置 | クラウドIDEのメニュー。上の「ビルド」の訳語にそろえる |
| プロジェクト | 專案 | クラウドIDEのメニュー |
| 設定 | 設定 | クラウドIDEのメニュー。日本語と同じ字なので、かっこ書きは添えない |
| ヘルプ | 說明 | クラウドIDEのメニュー |
| 公開… | 公開… | プロジェクトメニュー。日本語と同じ字なので、かっこ書きは添えない |

| 新しいプロジェクトを作る | 建立新專案 | ダッシュボード |
