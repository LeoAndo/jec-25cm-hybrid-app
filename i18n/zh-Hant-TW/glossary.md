# 用語集：繁體中文（台灣）（zh-Hant-TW）

ハイブリッドアプリ開発技法の対訳表。訳すときは、この表の訳語を使う。新しく訳語を決めた用語は、行を足す。全言語に共通の翻訳ルールは `skills/translate-teaching-materials/SKILL.md` にある。翻訳PRと照合を経て、訳語の確認を完了した。

## Monacaの画面に出る言葉（日本語のまま残し、訳をかっこで添える）

## 書き方の決まり

- **台湾で使う語彙にする。** 香港・中国の言い方と分かれる語は、次の表の「台湾」の列の訳を使う。

  | 日本語 | 台湾（この用語集） | 使わない言い方 |
  | --- | --- | --- |
  | コード | 程式碼 | 代碼 |
  | プログラム | 程式 | 程序 |
  | ソフトウェア | 軟體 | 軟件 |
  | ネットワーク | 網路 | 網絡 |
  | ファイル | 檔案 | 文件 |
  | フォルダ | 資料夾 | 文件夾 |
  | 画面・ディスプレイ | 螢幕 | 屏幕 |
  | マウス | 滑鼠 | 鼠標 |
  | デフォルト | 預設 | 默認 |
  | サーバー | 伺服器 | 服務器 |
  | サポートする | 支援 | 支持 |
  | インターフェース | 介面 | 界面 |
  | 情報 | 資訊 | 信息 |
  | メモリ | 記憶體 | 內存 |
  | オブジェクト | 物件 | 對象 |
  | 文字列 | 字串 | 字符串 |
  | 配列 | 陣列 | 數組 |
  | ループ | 迴圈 | 循環 |
  | 動画 | 影片 | 視頻 |

- **字形は台湾の字形にする。** 「這裡」「哪裡」のように 裡 を使う（香港の 裏 は使わない）。地名は 台灣 と書く。
- **引用符は「」、引用の中の引用は『』。** 台湾の書き方なので、日本語のかぎかっこと同じ形になる。
- 句読点は全角（，。：；？！（））にする。
- **漢字と英字のあいだには半角スペースを入れる**（`在 Visual Studio Code 中開啟`、`由 AI 翻譯`）。`config/i18n.json` の教科書UIの文言（`按 ⌘ C 複製`）も、この書き方にそろえてある。
- 手順の指示は「請按一下 **Run**。」のように、請 を付けた丁寧な命令の形にそろえる。
