## 書き方の決まり

いまのカタログでそろっている書き方を書いた（#185）。カタログの中で割れていて、まだ決めていない書き方は、この節の最後に挙げた。

- Unicodeミャンマー語で書き、Zawgyiは使わない。
- 文末は `။`、文の中の区切りは `၊` にする。日本語の句点「。」と読点「、」は、日本語のまま残す画面の文（`「保存できませんでした。」`）、`<code>` の中、コード欄の見出しのコードの断片（`&lt;p&gt;好きなものノートを作ります。&lt;/p&gt;`）の中だけに残す（#185 で、F01 の1文の文末の「。」を `။` に直した）。
- 英字の語（技術用語・製品名・`STEP`・コード欄の見出しのパス）とミャンマー語のあいだには、前もうしろも半角スペースを入れる（`Onsen UI ၏ စာရင်း`、`code ကို`）。`၊` と `။` は、英字の直後でもスペースを入れずに続ける（`HTML၊ CSS`）。カタログでは、英字とミャンマー文字が直接くっついた箇所は0件。
- 助詞（ကို、၏、မှ、တွင်、နှင့်、သို့、ရှိ、များ、ဖြင့် など）は、ミャンマー語の名詞にはつなげて書き（`စာရင်းကို`、`Web အခြေခံနှင့်`）、英字の語のうしろでは半角スペースを入れて書く（`code ကို`、`list ကို`）。カタログの例外は0件。
- 技術用語は英字で書く（用語集の冒頭）。この授業の用語で決めた語（code、field、named argument、reset など）は「この授業の用語」の表に従う。
- Monaca の画面の言葉（`<code>クラウドIDEで開く</code>` など）は日本語のまま残し、半角スペースと半角の `()` で、用語集の「Monacaの画面に出る言葉」の表の英語を添える（`<code>クラウドIDEで開く</code> (Open in the cloud IDE)`）。図の説明文（`img alt`）でも、学生が画面で探す言葉は同じように残す（#185）。
- アプリの画面に出る日本語は「」ごと日本語のまま残し、半角スペースと半角の `()` で意味を添える（`「まだ選択していません」 (Nothing selected yet)`、`「1つ戻す」 (Undo)`）。同じボタンの添え訳は、単元が変わっても同じ文字にする（#185 で「1つ戻す」「詳しく見る」をそろえた）。
- かっこは半角にし、前に半角スペースを入れる（`… (Minimal template)`）。前にスペースのないかっこは、コード欄の見出しのコードの断片（`ons.platform.select("android");`）の中だけ。
- 全角のコロン「：」は、半角のコロンと半角スペースにする（`အထွေထွေ: အခက်အခဲရှိသည့်အခါ`）。日本語のまま残す画面の文の中の「：」（`「登録件数：」`）はそのまま。
- 矢印 `→` はそのまま残す（`<code>表示</code> (View) → …`）。
- `STEP 01` などのSTEP番号は英字のまま。STEPの上の小見出しは `STEP 01 · အတန်းချိန် 1` の形（75件すべて）。
- 共通資料へのリンクとサイドバーは `အထွေထွေ: …` の形（「共通：はじめの準備」＝`အထွေထွေ: အတန်းမစမီ ပြင်ဆင်ရန်`）。本文の「共通資料：困ったとき」は `အထွေထွေလမ်းညွှန်: အခက်အခဲရှိသည့်အခါ`。単元の名前（`M01：OshiList` など）は訳さない。
- コード欄の見出しは `<パス> · <変え方> · <範囲>` の形。変え方は「この授業の用語」の表の3語（ထည့်ရန်／အစားထိုးရန်／ဖိုင်တစ်ခုလုံး အစားထိုးရန်）。
- 「困ったとき」の表の見出しは、状態＝`အခြေအနေ`、確認するところ＝`စစ်ဆေးရမည့်အရာ`。

次の書き方は、いまのカタログで単元によって割れていて、まだ決めていない（#186）。新しく訳す文は、同じページの既訳の書き方に合わせる。

- 数字（0〜9 とミャンマー数字）
- 引用符（“…” と ASCII の "…"）
- 範囲の記号（en dash「–」と「〜」）
- STEP の見出しの終わり方、確認欄の文の終わり方
- 文頭の英字の大文字・小文字（Monaca系は小文字、Flutter系は大文字）
- 画面の日本語に添える訳の言語（英語が多く、ミャンマー語のものがある。jec-25cm-kotlin はミャンマー語）
- 「画面」「ファイル」を英字で書くか、ミャンマー語で書くか
- ミャンマー語の文の中の ASCII のカンマ、題名の区切り（「: 」と「 - 」）
