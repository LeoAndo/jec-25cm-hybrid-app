ハイブリッドアプリ開発技法の対訳表。訳すときは、この表の訳語を使う。新しく訳語を決めた用語は、行を足す。全言語に共通の翻訳ルールは `skills/translate-teaching-materials/SKILL.md` にある。メモに「要確認」とある行は、訳語に自信がないもの。翻訳PRで確かめたら「要確認」を消す。

## 書き方の決まり

右から左の文の中での見え方は、Google Chrome で文字ごとの表示位置を測って確かめた（2026-09-25、issue #39）。

- **日本語や英語のまま残す言葉が記号（。、…！？）で終わるときは、その記号のすぐうしろに `&lrm;` を書く。** 書かないと、うしろに続くアラビア語や文の終わりに引かれて、その記号が言葉の反対側へ回り込み、「。保存した記録を読み込みました」「…File &gt; Open Folder」のように見える。この決まりは2026-09-25のオーナー決定で、jec-25cm-kotlin でも同じにする（あちらの用語集は決定の前にマージされたので、2026-09-25時点では「見えない文字を入れない」のままで、直している途中）。
  - **文字そのもの（U+200E）ではなく、`&lrm;` という6文字で書く。** カタログの上で目に見えるので、レビューで見落とさず、コピーしたときにも紛れ込まない。`&lrm;` はページでは「左から右」を示す見えない文字になる。向きを変える見えない文字（U+200E・U+200F・U+061C・U+202A〜U+202E・U+2066〜U+2069）をそのまま入れた訳は、対訳カタログの検査（`check`・`merge`）で落ちる。

  ```text
  原文：「保存した記録を読み込みました。」、追加した習慣、回数、詳細の理由を確認します。
  訳文：تحقق من ظهور 「保存した記録を読み込みました。&lrm;」 (تم تحميل السجل المحفوظ.)، ومن العادة المضافة، …
  原文：File &gt; Open Folder…でF01StampBoardそのものを開く。
  訳文：افتح F01StampBoard نفسه من File &gt; Open Folder…&lrm; في Visual Studio Code، …
  ```

  次の場合は書かなくてよい。どれも正しく並ぶことを確かめてある。
  - `<code>`・`<kbd>` の中（<code>プロジェクト → 公開…</code>、<code>let count = 0;</code>）。CSSで左から右に並べている。
  - `<strong>` の中（<strong>好きなものノートを作ります。</strong>）。CSSで、中の最初の文字の向きに並べている。
  - 記号で終わらない言葉（「テキストを変更」）。
- **コード欄の見出し（`<パス> · <変え方> · <範囲>`）の範囲に出るコードの断片は、`<code>` に入っていない。** 記号で終わる断片はうしろに、記号で始まる断片は前にも `&lrm;` を書く（`السطر &lrm;// ons.platform.select("android");&lrm;`、`السطر canPop: true,&lrm;`、`أسفل &lrm;];&lrm; الخاص بالمصفوفة oshiItems`）。書かないと、記号が断片の反対側へ回り込む。そのような断片を、アラビア語の文の（）の中に入れない（`});` の `)` が外側の `(` と組になり、`&lrm;` があっても並びが崩れる）。開きかっこを含む断片と閉じかっこを含む断片を、間にアラビア語をはさんで並べない（`من setState(() {&lrm; … إلى &lrm;});&lrm;` は、括弧の組がアラビア語をはさんで、断片が逆順に見える）。範囲は `setState(() { … });&lrm; في نهاية submit` のように1つの断片にまとめて書く（2026-10-23、#182。照合の担当が Google Chrome で表示位置を測って確かめた）。
- **「」は、日本語のまま残す言葉を囲むときだけ使う。** 右から左の文の中でも、かっこは向きを反転して正しく囲む形で出る。
- **アラビア語で書く操作や処理の並びは、矢印を ←（U+2190）にする。** 右から左に読むので、次の段階は左にある。→ のままだと、逆の順番に見える。日本語や英語のまま残す部分の中の → は、原文のまま残す（その部分は左から右に並ぶ）。

  ```text
  原文：入力→追加→詳細→戻る→再読み込みの順で動かし、
  訳文：شغّل التطبيق بالترتيب: الإدخال ← الإضافة ← التفاصيل ← الرجوع ← إعادة التحميل، …
  原文：クラウド IDEの <code>プロジェクト → 公開…</code> を開き、
  訳文：افتح <code>プロジェクト → 公開…</code> (مشروع ← نشر…) في بيئة التطوير السحابية، …
  ```

- **`<strong>` の中は、英字や日本語で書き始めてアラビア語を続けない。** `<strong>` は中の最初の文字で向きが決まるので、英字で始めると左から右に並び、読む順が逆になる。アラビア語を先に書く（<strong>ملف Dart</strong>）か、英字・日本語だけを入れる。
- **数字は 0〜9（西洋数字）で書く。** STEP番号・コード・画面の表示と同じ数字にする。アラビア・インド数字（٠١٢٣）は使わない。
- **句読点はアラビア語のものを使う。** 読点は「،」、疑問符は「؟」、セミコロンは「؛」。文末は「.」。
- **引用符は «…»。** 画面やアプリに出る日本語を囲むときは「」のまま残す（上の決まり）。
- **手順と学生への呼びかけは、命令形の男性形を総称として使う**（افتح، اختر، انقر）。アラビア語のソフトウェアの手順書の慣例に合わせた。先生は المعلم と書く。`config/i18n.json` のUI文言と翻訳の注記（فاسأل المعلم）も、この書き方にそろえてある。全単元で一貫性を確認済み。
- **母音記号（ハラカート）は付けない。** 読み違えやすい語だけ、シャッダ（ّ）を付けてよい（نزّل، شغّل）。
- **英字の製品名やコード名に、定冠詞 ال を直接付けない。** 名詞を添えて書く（إطار Flutter، حزمة shared_preferences）。
